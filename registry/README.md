# The Registry

**This directory is deliberately empty in the public repository.**

By founding decision (ratified 2026-07-06), testimony text never
lives in this repository. What you are holding is the transparency
instrument: the event log (`../log/`) records a fingerprint of every
testimony ever entered or withdrawn, and `../tools/verify.py` proves
the chain — but the words themselves are browsable only on the
official website, allhumans.world, and complete archive snapshots
are distributed solely to trusted preservation partners under formal
deposit agreements.

On the operator's working copy, this directory holds one folder per
human, named by nine-digit Registry number: `entry.json` (the permanent
entry, schema `../schema/entry.v2.json`) and `versions/` with at
most `1.json`, `2.json`, `3.json` — the First, Second, and Final
Testimonies.

`000000001/` will never exist anywhere. Public numbering begins at
`000000002/`.
